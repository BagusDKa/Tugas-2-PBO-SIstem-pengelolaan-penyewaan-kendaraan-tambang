# Tugas-2-PBO-SIstem-pengelolaan-penyewaan-kendaraan-tambang
Class utama (driver) yang menampilkan menu dan mengatur alur program Sistem Pengelolaan Penyewaan Kendaraan Tambang
Perulangan utama program terus berjalan sampai user pilih menu Keluar
Validasi input menu: harus berupa angka,Validasi input string tidak boleh kosong, Validasi input harus angka desimal dan lebih dari 0 
Class entitas untuk merepresentasikan data kendaraan tambang Menerapkan encapsulation semua atribut private akses melalui getter/setter.
Class pengelola yang bertugas menyimpan dan mengelola data KendaraanTambang menggunakan ArrayList
 Encapsulation ArrayList disimpan sebagai atribut private
